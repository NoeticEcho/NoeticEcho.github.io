NoeticEcho · open source

Open systems for meaning, cognition and human–AI collaboration.

We build software in which meaning is a first-class object: a world you can walk whose atmosphere is computed from what it means, agents (iskins) with their own memory and voice, and a language (NSL) for describing both. Along the way we open-source the tools we could not find.

Meaning should not disappear when software begins.

Open now

Five open projects you can use today

The code of all five is under the Apache-2.0 licence; the textbook's lessons are under CC BY-SA 4.0.

control-room

open

One person, one AI coordinator, many AI coding agents. A protocol, prompts and scripts for running them in parallel, each on its own branch, with one desk for the decisions only the person can make.

Roles
The owner decides. The coordinator plans, briefs and lands. Each worker carries one epic to a pull request.
Runners
Claude Code cloud sessions, Codex, e2b sandboxes or local git worktrees.
Checks
local-ci runs them on your own machine and posts the verdict as a commit status. No Actions minutes.
Read the docs → Repository

noetic-harness

open

A development harness for AI coding agents. A repository writes down how it is developed in an .agents/ directory, and the harness holds the agents to it: each piece of work goes to a workflow and the smallest team of roles that covers it, and a step reported done without evidence is refused.

Engine
Routing, gate lanes, a run ledger that runs the gates itself, a project memory, and an evolution engine with holdouts against Goodhart. One executable for Linux and macOS.
Packs
A starter pack of thirty roles and generic workflows, and a full catalogue of more than two hundred roles.
Claude
In Claude Code, noetic-harness sync sets up the whole harness, MCP server and subagents. The Claude plugin carries the roles and the method where nothing can be installed.
noetic-harness init && noetic-harness sync
Repository → Release 0.6.0 Install Claude plugin

TypedbEx

open

An Elixir driver for TypeDB 3.x. Two packages decode into the same structs and fail with the same error, so changing the transport is a line in your data-access module.

typedb
The HTTP API. One dependency, debuggable with curl, faster for many small independent reads.
typedb_grpc
gRPC. Large reads streamed lazily on the BEAM, pipelined reads, database export and import.
{:typedb, "~> 0.11"}
Repository Docs Hex: typedb typedb_grpc docs

reminisce

open

Agent memory on TypeDB: an Elixir library with an MCP server. It stores what an agent decides to keep, and it never deletes a memory. A foundation, not a framework: it calls no model and uses no vectors in this release.

Remembers
With time, provenance, a subject's consent scope and status. Every call is scoped to an owner, and secrets are refused before any write.
Recalls
Deterministically: the same store and query give the same order. why/4 explains a memory: its sources, what it superseded, what contradicts it.
Withdraws
A subject's words can be erased on request. The README lists what erasure does not reach.
{:reminisce, "~> 0.5"}
Repository → Docs Hex: reminisce Design

Through Time Сквозь время

open

An interactive textbook of the whole web, in Russian, for people who have never built a site: from the first page of 1991 to the agentic web. You learn on your own project, and the site you describe at the start is rebuilt era by era. Perhaps the last textbook of the pre-AI era: for those who want to understand the magic, not only use it.

Course
Seventeen parts: how the internet works, HTML and CSS, design systems, JavaScript, servers, data, infrastructure, copywriting and marketing frameworks, storytelling, metrics, quality and law, and AI. Being written now, part by part.
Practice
A sandbox in the browser checks the page you build; spaced repetition keeps what you learned; a guide called Echo walks with you.
Private
No registration and no analytics. Progress stays in your browser and exports as a file.

In development

EchoBaby

A walkable world of meaning. It is built in Elixir: Ash, Phoenix and Jido, with TypeDB and Qdrant. A BabylonJS client renders it, with the Observer seen from behind in a hooded cloak. Its first public milestone is a site and a world that anonymous visitors can enter.

How we work

Six rules we hold ourselves to

  1. Models propose, validators decide, runtimes execute.

  2. Meaning is kept apart from geometry, UI and rendering.

  3. Everything generated carries its provenance.

  4. Projections are views, never the source of truth.

  5. The system represents what people express. It does not claim to know their inner state.

  6. A specification is not proof that an implementation exists.We say which is which.
