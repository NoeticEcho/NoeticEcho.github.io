NoeticEcho · open source

Open systems for meaning, cognition and human–AI collaboration.

We build software in which meaning is a first-class object: a world you can walk whose atmosphere is computed from what it means, agents (iskins) with their own memory and voice, and a language (NSL) for describing both. Along the way we open-source the tools we could not find.

Meaning should not disappear when software begins.

Open now

Two repositories you can use today

Both are under the Apache-2.0 licence.

control-room

open

One person, one AI coordinator, many AI coding agents. A protocol, prompts and scripts for running them in parallel, each on its own branch, with one desk for the decisions only the person can make.

Roles
The owner decides. The coordinator plans, briefs and lands. Each worker carries one epic to a pull request.
Runners
Claude Code cloud sessions, Codex, e2b sandboxes or local git worktrees.
Checks
local-ci runs them on your own machine and posts the verdict as a commit status. No Actions minutes.
Read the docs → Repository

TypedbEx

open

An Elixir driver for TypeDB 3.x. Two packages decode into the same structs and fail with the same error, so changing the transport is a line in your data-access module.

typedb
The HTTP API. One dependency, debuggable with curl, faster for many small independent reads.
typedb_grpc
gRPC. Large reads streamed lazily on the BEAM, pipelined reads, database export and import.

In development

EchoBaby

A walkable world of meaning. It is built in Elixir: Ash, Phoenix and Jido, with TypeDB and Qdrant. A BabylonJS client renders it, with the Observer seen from behind in a hooded cloak. Its first public milestone is a site and a world that anonymous visitors can enter.

How we work

Six rules we hold ourselves to

  1. Models propose, validators decide, runtimes execute.

  2. Meaning is kept apart from geometry, UI and rendering.

  3. Everything generated carries its provenance.

  4. Projections are views, never the source of truth.

  5. The system represents what people express. It does not claim to know their inner state.

  6. A specification is not proof that an implementation exists.We say which is which.
